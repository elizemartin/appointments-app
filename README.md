## Getting Started

### Clone the Repository

```bash
git clone https://github.com/elizemartin/appointments-app.git
```

### Navigate to Project Directory

```bash
cd appointments-app
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Open in Browser

```
http://localhost:5173
```
